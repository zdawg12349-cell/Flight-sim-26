## Engine and environment sounds

The real recordings in `assets/audio/audiopack.js` come from open-source [FlightGear](https://www.flightgear.org/) aircraft and base-data repositories. Every source repository was checked for its licence before use; all of them are licensed under the **GNU General Public License, version 2** (the CRJ700 family under "version 2 or above"). The full licence text is in [`assets/audio/COPYING.GPL-2.0`](assets/audio/COPYING.GPL-2.0).

The sound pack is a separate data file loaded at run time (an aggregate with the MIT code, not a derivative of it), and it stays under GPL-2.0. You may redistribute and modify it under those terms.

**Modifications** (made by `tools/build_audio.py`): clips were trimmed, given seamless crossfaded loop points, converted to mono, resampled, peak/RMS normalised, encoded as Ogg Vorbis and embedded as base64 so the simulator runs from `file://`. No other changes were made. The corresponding source (the original WAV files) is available from the repositories linked below, at the paths listed. To rebuild the pack: `python3 -I tools/build_audio.py <folder with the cloned repositories>`.

Files are copied into the project. Nothing is hotlinked.

## Synthesised sounds

The propeller blade-pass tone, the turbofan buzz-saw, afterburner rumble, emergency-vehicle sirens, the fire bell and the GPWS altitude call-outs (Web Speech API, when available) are generated at run time and are not recordings.

## Fonts and imagery

There are no third-party images, textures or fonts. All textures (terrain, runways, liveries, signs, instruments) are drawn procedurally at run time. The UI uses the system font stack.
